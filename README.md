# Walter

The Walter software in its vision tree (core, cognition, capabilities, ops, lab), each module at its path with its
full history (published from the machine by `walter-git-publish`). Personal data, keys and the owner's history are never here: they live in the user folder.
Known secret values and credential shapes are replaced by `«secret:vault»` / `<secret:redacted>` before publishing.
