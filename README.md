# Walter

The Walter software, one folder per module, each with its full history (published from the machine by
`walter-git-publish`). Personal data, keys and the owner's history are never here: they live in the user folder.
Known secret values and credential shapes are replaced by `«secret:vault»` / `<secret:redacted>` before publishing.
