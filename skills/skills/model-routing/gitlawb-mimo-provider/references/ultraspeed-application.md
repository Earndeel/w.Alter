# MiMo UltraSpeed Application Process

## Platform URLs
- **Application form:** `https://platform.xiaomimimo.com/ultraspeed`
- **Chat interface (free during trial):** `https://ultraspeed.xiaomimimo.com`
- **Auth:** `https://account.xiaomi.com` (Xiaomi account required)

| Field | Required | Type |
|-------|----------|------|
| Your name | ✅ | Text |
| Phone number | ✅ | Country code dropdown (+86 default) + number |
| Email | | Text |
| Company name | | Text |
| Industry | | Dropdown |
| Your use case | | Dropdown |
| Anything else | | Textarea (500 car. max) |

## Access Flow
1. Login with Xiaomi account on `platform.xiaomimimo.com`
2. Fill application form on `/ultraspeed`
3. Wait for daily approval batch
4. Once approved: API access at 3× standard MiMo Pro pricing
5. Chat UI is free during the trial window

## Notes
- Trial capacity is limited — "prioritized for professional organizations"
- Approval is not guaranteed even after submission
- The +86 phone prefix is China default but changeable to any country code
- Business inquiries: `business-mimo@xiaomi.com`
