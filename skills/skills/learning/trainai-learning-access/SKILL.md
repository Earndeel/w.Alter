The site is trainaiuniversity.learnupon.com. Back up browser_sites configuration before changes. If that host yields zero cookies, inspect only metadata for the tenant and LearnUpon parent. Stop before examinations, attestations or qualification submissions. Report observed progress and lesson titles, never inferred completion.
