# Side-effect branches

## Communication delivery

Resolve route, destination, account, consent, thread/call identity, and idempotency key before dispatch. Track accepted, queued, connected, media-delivered, application-complete, and recipient-visible states separately. On timeout, query remote state before retrying. For telephony, inspect DNS/network, SIP registration, auth, dialplan, RTP, codec, and application handoff independently.

## Administrative forms

Resolve jurisdiction and exact supporting documents before calculating fields. Preserve the source-to-field derivation; never invent, understate, or silently round material values. Use the form's correct overlay/fill mechanism, render the result, inspect line alignment and overflow, keep signatures truthful, and verify attachment coherence before submission.

## Approval and read-back

Present proposed recipients, actions, amounts, documents, and risk before mutation. After any write or ambiguous provider response, read back the exact external record or artifact and report partial or unknown outcomes instead of retrying blindly.
