# Task intent and artifact resume checklist

Use this before a paid video action or when a user says “continue”, “video 2”, “second clip”, or “the other video”.

## Classify the operation

- **Generate / launch / attack**: submit a new provider task, or recover the exact task if it already exists.
- **Resume / check status**: inspect the same provider project/task and recover its output without resubmitting.
- **Review / audit / inspect**: analyze an existing MP4; no generation or edit is implied.
- **Edit / clean / assemble**: create a derived artifact only after the target file and intended change are identified.

Never let a filename decide the operation. `clip_b.mp4` may be a second half of a connected ad, an export from an earlier attempt, or merely the nearest local file; map it to the user’s brief first.

## Resolve target identity

Record these labels before acting:

- project/campaign and brief;
- user-facing number or variant (“video 2”, “B”, “second half”);
- provider and model/interface;
- task ID or project URL;
- local artifact path and measured state;
- whether the artifact is queued, complete, reviewed, edited, or only a candidate.

If two labels may refer to different assets, state the ambiguity and ask one narrow question before spending credits. Do not silently substitute an audit for a generation.

## Resume without duplicate billing

1. Check the provider project/collection and task record first.
2. If the exact task is queued or complete, reuse its task ID and download/review the result.
3. If only a local candidate exists but its task identity is unverified, call it “existing candidate inspected”, not “video 2 generated”.
4. Before any paid action, state in one sentence: target, operation, provider, and expected spend/approval point.
5. After the action, report exactly what happened: generated, resumed, audited, edited, or not launched.

## Communication guardrail

When the user says “continue with the second video”, lead with a plain confirmation of the action taken. If no new generation was launched, say so immediately; do not lead with a long QA verdict that makes a different operation sound completed.
