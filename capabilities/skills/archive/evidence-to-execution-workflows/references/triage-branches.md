# Evidence triage branches

## Inbox

Resolve account, folders, time window, timezone, pagination, and mutation bounds before retrieval. Read complete threads, classify each as urgent reply, reply, action without reply, waiting, reference, or noise, draft in context, keep send/delete/archive behind approval, and inspect provider state before retrying an ambiguous send.

## Meetings

Separate decisions, proposals, commitments, questions, blockers, risks, and context. Give every action an explicit outcome, owner, due date, dependency, acceptance condition, and source; use `unresolved` instead of inference. Search existing trackers before creating records and read back every approved write.

## Teams operations

Validate configuration, token health, and Graph subscriptions before diagnosing missing meetings. Use stored-job list/show/fetch/run operations, renew subscriptions before the 72-hour expiry, distinguish transcript delay from consent, delivery, or webhook failures, and verify the recipient-visible summary.

## Weekly review

Cover the completed period and planning horizon across declared calendars, tasks, notes, inboxes, and projects. Reconcile waiting items, stalled projects, capacity, and deferred work; propose a small plan; and mutate only approved records, reading each one back.
