# Public-web research branches

## Blocked pages

After a 403, 429, WAF, paywall, login wall, or bot interstitial, stop repeating the unchanged request. Escalate through permitted archives, same-host APIs/feeds, or a real browser; validate the body rather than status/size; and label snapshots with their date.

## Citations

Register sources at retrieval time, cite while drafting, attach verbatim evidence for high-stakes claims, render source lists mechanically, and verify every citation. Search snippets and URLs do not support claims whose source body was never retrieved.

## Rights-aware downloads

Resolve exact title, creator, edition, and format. Classify access as authorized public download, public-domain/open-license, controlled lending, preview, or paid/DRM; download only authorized public files; never bypass access controls; and report when no lawful free copy exists.

## Recurring monitoring

Freeze entities, aliases, domains, categories, cadence, cutoff, materiality threshold, source coverage, and deduplication key. Use overlap for late indexing, treat failed sources as coverage gaps, collapse syndicated reports into one event, and separate observed change, significance, and confidence.

## X API operations

Keep secrets outside agent context: use `xurl auth status`, never read `~/.xurl` or use verbose/inline-secret flags, perform a cheap read before writes, confirm exact targets, and require approval for posts, messages, and account mutations. Keep X API observations distinct from identity confirmation.
