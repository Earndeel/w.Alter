# Project Brief and Approval-Gate Template

Use this as a compact working document. Keep evidence IDs/timestamps in the internal notes; show Monsieur only the evidence needed for a decision.

## Source check

- Contact resolved: `yes / no`
- Chat type: `single / group`
- Network:
- Current time in Bangkok:
- Latest relevant message: `DD/MM HH:mm`
- Outgoing side present: `yes / no / incomplete`
- Messages paginated far enough: `yes / no`
- Voice notes: `none / transcribed / unavailable`
- Linked sources: `inspected / unavailable / not relevant`
