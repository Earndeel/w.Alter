# W.Alter Access

Double-cliquez sur **install.command** pour donner à W.Alter l'accès complet à ce Mac.

## Ce que ça installe

| Composant          | Rôle                                      |
|--------------------|-------------------------------------------|
| Tailscale          | VPN privé chiffré entre votre Mac et W.Alter |
| SSH                | Accès terminal (commandes, fichiers)       |
| Screen Sharing     | Accès écran + clics (VNC)                  |
| Tunnel persistant  | Reconnexion automatique après mise en veille |

## Pour couper l'accès

Double-cliquez sur **offswitch.command** → tout est désactivé immédiatement.

## Prérequis

- macOS 12+ (Monterey ou plus récent)
- Connexion Internet
- Votre mot de passe administrateur

## Après installation

Laissez le dossier sur le Bureau — comme ça vous avez toujours
le bouton off sous la main.
