description: >
  Create a distributable macOS installer package that gives W.Alter full remote access
  (SSH + VNC/Screen Sharing + Tailscale + persistent reverse tunnel) to a friend's or
  client's Mac. Includes the off-switch pattern for the remote user to kill access.

## Trigger
When W.Alter needs to onboard a new Mac for remote control — SSH terminal access,
VNC screen sharing with click capability, and a user-side kill switch.

## The stack (what gets installed)

| Layer | Component | Purpose |
|-------|-----------|---------|
| VPN | Tailscale | Encrypted private network, no open ports |
| Terminal | SSH (Remote Login) | Shell, file ops, package installs |
| GUI | Screen Sharing (VNC) | Screenshots + mouse clicks |
| Persistence | launchd + autossh | Auto-reconnect after sleep/reboot |

## Package structure

```
walter-access/
├── install.command      ← Double-click to install everything
├── offswitch.command    ← Double-click to kill all access
├── walter_key.pub       ← W.Alter's SSH public key
└── README.txt           ← Plain-text instructions
```

## Key design decisions

### Why `.command` not `.pkg`
Apple notarization costs $99/year. `.command` scripts work with a one-time
right-click → Open bypass of Gatekeeper. Good enough for one-on-one onboarding.

### Why VNC over cliclick
cliclick needs Accessibility permissions (manual System Prefs toggle) AND
an active GUI session. VNC is built-in, handles screen lock, and lets W.Alter
see + click in one protocol. We still install cliclick optionally for
programmatic clicks from SSH.

### The off-switch pattern
The remote user MUST be able to revoke access instantly without W.Alter's help.
The offswitch.command kills: Screen Sharing service, SSH tunnel launchd job,
active SSH sessions, and optionally Remote Login itself.

## Prerequisites on the target Mac
- macOS 12+ (Monterey or newer)
- Admin account (sudo required for Tailscale + system services)
- Internet connection
- Tailscale auth key (generated by W.Alter from admin.tailscale.com)

## Templates

- `templates/install.command` — the main installer script
- `templates/offswitch.command` — the kill switch
- `templates/README.txt` — user-facing instructions

## Usage flow

1. Generate a Tailscale auth key (admin.tailscale.com → Settings → Keys)
2. Copy the `walter-access/` template, insert the key and W.Alter's SSH pubkey
3. Zip and send to the remote user
4. Remote user: unzip → double-click install.command → enter admin password 3-4 times
5. After the session: remote user double-clicks offswitch.command
